# Quiz sound effects

Add your own audio here (case-sensitive filenames):
- `Clock.mp3`: each new question, when its clocks appear.
- `Correct.mp3`: correct answer.
- `Wrong.mp3`: wrong answer or timeout; defeat challenges wait 900ms before closing.

Files are copied automatically by `npm run build`. Missing files or browser autoplay
restrictions do not block the quiz. No audio files are bundled yet.
